# PR-кампания с ИИ: материалы вебинара

Материалы для участников вебинара в Нейроцехе 8 октября 2026 года. Дарья Руцинская, журнал «Контекстема», kontekstema.ru

| Файл | Что внутри |
|---|---|
| `1_PR-кампания_с_ИИ_12_шагов_и_промпты.pdf` | 12 шагов кампании, на каждом промпт и что должно получиться на выходе; шаблон паспорта фактов; чек-лист перед первым письмом журналисту |
| `2_Красная_команда.pdf` | Семь промптов, чтобы прочитать кампанию глазами журналиста, конкурента и скептика до выхода, и план первого часа кризиса |
| `3_Аналитическая_панель_и_индекс.pdf` | Три смысловые метрики и промпт для разметки мониторинга, четыре ячейки и формула индекса контекстемы, таблица самопроверки за вечер |
| `4_Скилл_редактор_текстов_для_Claude.zip`, папка `redaktor-tekstov` | Скилл «Редактор текстов» для Claude: свод правил ясного письма по мотивам «Пиши, сокращай» |
| `4_Редактор_текстов_для_ChatGPT_и_GigaChat.md` | Тот же свод текстом для инструкций проекта в ChatGPT, GigaChat и других нейросетях |
| `Материалы_вебинара.zip` | Все файлы одним архивом |

Скачать все: зеленая кнопка Code → Download ZIP, или файл `Материалы_вебинара.zip`.

## Как подключить скилл

**Claude.** Загрузите `4_Скилл_редактор_текстов_для_Claude.zip` в настройках Claude, в разделе скиллов. В Claude Code положите папку `redaktor-tekstov` в `~/.claude/skills/`. После этого достаточно попросить «напиши пост» или «отредактируй текст».

**ChatGPT, GigaChat и другие.** Вставьте текст файла `4_Редактор_текстов_для_ChatGPT_и_GigaChat.md` в инструкции проекта или своего GPT. Если такой настройки нет, вставьте его первым сообщением в новый чат: «Работай по этим правилам со всеми моими текстами».

Методика индекса контекстемы открыта на kontekstema.ru/indeks.
